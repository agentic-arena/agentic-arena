## Ideas

The design rules inside the anti-slop skill adapt ideas from these projects. Licenses were checked from
the repositories, not from memory.

| Project | License | What we took |
| --- | --- | --- |
| taste-skill, Leonxlnx | MIT | ban list concepts, the three locks, hero discipline, pre-flight checklist |
| Vercel Web Interface Guidelines | MIT | keyboard and focus rules, tap target sizes, reduced motion, transition-all ban |
| awesome-design-md, VoltAgent | MIT | the DESIGN.md artifact format, originally a Google Stitch idea |
| Impeccable | Apache 2.0 | product record before pixels, evidence based claims, critique and polish loop |
| playwright-cli, Microsoft | Apache 2.0 | the cli shaped browser tool this audit script grew from |

No files from those projects are copied into this repository.
